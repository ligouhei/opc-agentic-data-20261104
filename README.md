# OPC Agentic 客户讲解网页

数据管线、工艺环境、质量保障、真实任务 Demo 与知识库迭代。

## 本地查看

直接打开 `index.html`，或在当前目录运行 `python3 -m http.server 4173` 后访问 http://localhost:4173 。零构建依赖。

## 内容

- 数据构造与工艺数值用途总览，软件与方法多样性。
- opc-tf5-0001 实际 R0 / A / B 阶段切换、五工况原始打印图、任务 Prompt 和冻结指标。
- opc-0636 黑白掩模与打印红蓝差异；0156 指标盲点及 Serif/SRAF 实测。
- 可放大图片、可复制 Prompt、图文材料下载。

此处为已完成实验的记录回放。0156 尚未实现保持中点与线宽同时恢复方形；突破 teacher 上限是待评测目标。数据和实验截至 2026-11-04。
